## Wireframe: один потік (персона Olena)

1. **Dashboard** — дедлайни тижня, чесний прогрес за балами (зароблено з усіх можливих), картки курсів → «Open course».
2. **Course page** — теми з лекціями й лабораторними, чат курсу, найближчі події → «Open lecture».
3. **Lecture view** — слайди з AI-конспектом, власні нотатки й поле питання до AI; «Back» повертає на сторінку курсу.
