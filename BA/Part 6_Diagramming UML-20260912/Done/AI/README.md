# Частина 6. UML-діаграми (AI-версія)

**Проєкт:** «VNS» · **Команда:** «20/80» · **Мова діаграм:** англійська
**Функція:** AI-помічник на сторінці лекції та AI-інструменти навчання (питання, конспект, тест, картки). Ключовий прецедент **UC-1** «Ask the AI assistant a question about a lecture» зі сценаріїв Частини 5 (AI).

Це той самий процес, що й у версії Manual (питання студента про лекцію), але описаний і намальований інакше: інші об'єкти й назви, інший порядок кроків, інші стани та структура компонентів. Компонентна й розгортальна діаграми охоплюють усі AI-інструменти (UC-1, UC-4, UC-5, UC-6), а не лише питання.

## Чим відрізняється від версії Manual

| Тема | Manual | AI-версія |
|------|--------|-----------|
| Об'єкти | `:LecturePage`, `:AiAssistant`, `:AiSettings`, `:MaterialIndex`, `:ExternalLlmClient` | `:AiPanel`, `:QuestionService`, `usage : DailyUsage`, `:GradedTaskGuard`, `:SlideSearch`, `:LlmGateway` |
| Порядок | доступ → ліміт → питання → пошук → LLM → показ → запис у лог | ліміт → оцінюване завдання → пошук → LLM → відповідь → **підрахунок** → показ |
| Підрахунок запиту | після показу відповіді | лише після того, як відповідь створена (відмова чи помилка запит не рахують) |
| Стани | `:AiAssistant` під час питання, `:AiUsageRecord` | `:AiPanel` (що бачить студент) і `usage : DailyUsage` з двома станами |
| Діяльність | fork для повідомлення «answer is being prepared» | fork для двох незалежних перевірок (оцінюване завдання і пошук слайдів) |
| Компоненти | один компонент на AI-помічника | компонент на кожен AI-інструмент (питання, конспект, тести й картки) і спільні `SlideSearch`, `LlmGateway`; ліміт — сутність `DailyUsage` |
| Розгортання | клієнт, сервер, БД | те саме плюс окремий веб-сервер Nginx і зовнішній LLM API |

## Припущення (їх треба підтвердити в команді)

1. **30 с** на відповідь LLM (`2.5a`, `after(30 s)`). У вимогах значення нема.
2. **Повідомлення 2.5a** (немає відповіді) у сценарії Частини 5 відсутнє. Його додано як у версії Manual.
3. **Підрахунок запиту** (повідомлення 2.7) виконується лише після створення відповіді. Перевірка доступу до курсу не показана: у Частині 5 AI це передумова UC-1.
4. **Об'єкти й класи** взято з оновленої діаграми класів Частини 5 (AI), `3. Class Diagram_VNS` (версія від 18/11/2026). Імена операцій (`process`, `remaining()`, `count()`, `isGradedTask`, `isGraded()`, `find`, `getText()`, `generate`) збігаються з нею. Якщо діаграму класів змінять, діаграми Частини 6 треба оновити.
5. **Технології** з розділу 7.1 `Ідея_проекту.md`: React / Next.js, Node.js (NestJS), PostgreSQL з pgvector, зовнішній LLM API. Один сервер застосунку на пілот.
6. **Таблиці** `course`, `lecture`, `slide`, `lab`, `ai_settings`, `daily_usage`, `ai_result`, `test_attempt` умовні (по одній на сутність або групу сутностей).

## Як створено

`.drawio` і `.png` згенеровано одним скриптом, тому вони збігаються між собою. PNG не експортовано з draw.io, а намальовано окремим рендером. `.drawio` перевірено лише як коректний XML і не відкривалось у draw.io. Після відкриття варто глянути, чи нічого не зсунулось, і за потреби експортувати PNG з draw.io.
